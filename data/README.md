# داده‌های دورهٔ کیدوتاکس — T3

این پوشه فقط داده است؛ هنوز به هیچ صفحه یا مسیر عمومی متصل نشده است.

- `types.ts`: نوع مشترک واژه، سؤال، فونیکس، خواندن، نوشتن و یونیت.
- `units/unit-01.ts` تا `unit-15.ts`: محتوای کامل هر یونیت با یک ساختار مشترک و کنترل `satisfies CourseUnit`.
- `index.ts`: خروجی مشترک `courseUnits` و نوع‌ها برای مراحل بعدی.
- `shared.ts`: هنر SVG، داده‌های مشترک، متن‌های اصلی و آرایه‌ها/اشیای ثابت داخل تابع‌های نمونه؛ نسخه‌های قدیمی و بازنویسی‌شده هر دو نگه‌داری می‌شوند.
- `verification-report.md`: نتیجهٔ آخرین تطبیق.

## حفظ متن و ساختار قدیمی

متن‌های انگلیسی و فارسی، علائم نگارشی، آپاستروف‌های مستقیم و خمیده و ترتیب واژه‌ها حفظ شده‌اند. هیچ ترجمه یا تصحیح آموزشی تازه‌ای اضافه نشده است.

`models` شامل جفت‌های متمایز انگلیسی/فارسی است. اگر متن انگلیسی یکسان اما ترجمه متفاوت باشد، هر دو باقی می‌مانند. `modelSets` محل اصلی هر مجموعه را نشان می‌دهد. `original` ورودی اصلی `COURSE` را بدون تغییر حفظ می‌کند.

گرامر یونیت ۱ از `BL`، یونیت ۲ از دو سؤال `my/your` و چهار پرسش مالکیت، و یونیت ۳ از ده سؤال `This is/These are` و پنج سؤال مفرد/جمع استخراج شده است. قواعد یونیت‌های قدیمی از متن اصلی `TEACH_TIPS` آمده‌اند؛ توضیحات قدیمی‌تر نیز در `lessonHtml` و محتوای مشترک موجودند.

`exerciseBanks` نسخهٔ ثابت سؤال‌ها با پاسخ‌ها، گزینه‌ها، متن شنیداری و صحنهٔ اصلی را حفظ می‌کند. برای سؤال‌های قدیمی که متن داخل HTML است، `prompt` خالی و `sceneHtml` حاوی متن و تصویر اصلی است. بانک‌های خام یونیت‌های جدید نیز در `original` موجودند؛ بنابراین تبدیل آپاستروف برای تلفظ در کد قدیمی، متن اصلی را از بین نمی‌برد.

`lessonHtml` فقط آرشیو دادهٔ نمایش درس، نوشتن، صحبت‌کردن، کاردستی و بازی قدیمی است؛ صفحهٔ جدید یا کد React نیست. این رشته‌ها دارای رویدادهای قدیمی‌اند و نباید مستقیماً اجرا یا بدون بازبینی به صفحه تزریق شوند. در T4/T5 از داده‌های تایپ‌دار استفاده شود.

۷ عنوان بخش برای همهٔ یونیت‌ها یکسان نگه‌داری شده، ولی نمونه برای یونیت‌های ۱ و ۳ فقط ۶ درس دارد؛ نبودن `extra` به معنای نبود محتوای آن در نمونه است. فونیکس یونیت ۷ مرور الفباست و عمداً لیست واژهٔ صوتی ندارد. برای یونیت‌های ۱ تا ۳ متن مستقل خواندن ورک‌بوک تعریف نشده است.

## تصاویر

`imageFile` و `sourcePages` فقط نام فایل‌اند، نه لینک عمومی. هیچ تصویر کتاب یا واژه‌ای کپی نشده است. نمونه برای واژه‌های یونیت‌های ۱ و ۳ SVG دارد؛ `emoji` برای آن‌ها `null` و `svg` حاوی تصویر اصلی است. `null` در صفحات دوم و سوم Student Book یونیت ۱۳ دقیقاً کمبود موجود در نمونه را نشان می‌دهد.

آرشیو متن و HTML می‌تواند رشتهٔ مسیر قدیمی را برای حفظ متن منبع داشته باشد؛ این رشته‌ها فایل تصویری نیستند و نباید به مسیر عمومی تبدیل شوند. ویدیوهای ذخیره‌شده نیز صرفاً داده‌های موجود در نمونه‌اند؛ انتشار یا تأیید ویدیوی جدید در این مرحله انجام نشده است.

## اجرا و بررسی

از ریشهٔ پروژه:

```powershell
node scripts/verify-data.mjs
node scripts/verify-data.mjs --self-test --write-report
npm run lint
npm run build
```

بررسی‌کننده محتوای فایل‌های TypeScript را بدون اجرای آن‌ها می‌خواند، هر مقدار و تعداد را با استخراج تازه از نمونه مقایسه می‌کند و علاوه بر آن واژه‌ها، عناوین، گرامر، خواندن، نوشتن، جمله‌ها و مراجع تصویر را مستقیماً با جدول‌های اصلی تطبیق می‌دهد. حذف، اضافه‌شدن یا تغییر متن با نام دقیق فیلد گزارش می‌شود و کد خروج غیرصفر می‌دهد. کمبودهای خود نمونه به‌صورت جداگانه گزارش می‌شوند.

آزمون `--self-test` هفت حذف/تغییر عمدی را فقط در حافظه ایجاد می‌کند و بررسی می‌کند که همه شناسایی شوند؛ فایل‌ها دست‌نخورده می‌مانند.

برای بازتولید داده‌ها فقط پس از تغییر عمدی منبع:

```powershell
node scripts/convert-data.mjs
```

اسکریپت استخراج از TypeScript موجود در پروژه و ابزارهای داخلی Node استفاده می‌کند. نمونه در محیط VM با DOM و ذخیره‌سازی ساختگی و بدون ابزار شبکه/فایل اجرا می‌شود؛ هیچ صفحهٔ مرورگر، تصویر یا اطلاعات کاربری خوانده یا ساخته نمی‌شود. لازم نیست بسته‌ای نصب کنید.
