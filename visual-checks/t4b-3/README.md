# نتیجهٔ T4b.3 — واژه‌های بیشتر

فقط بخش سوم درس پیاده شد. بخش چهارم و زیرکارهای بعدی شروع نشده‌اند.

## محتوا و فایل‌ها

- هر ۷۷ واژهٔ بخش سوم از دادهٔ موجود `data/units` با `section=3` خوانده می‌شود؛ متن آموزشی، ترجمه و ترتیب تغییر نکرده است.
- تعداد واژه‌ها برای یونیت‌های ۱ تا ۱۵: `5, 5, 5, 5, 5, 3, 5, 5, 5, 5, 5, 5, 10, 4, 5`.
- ۵۲ تصویر موجود از `legacy/assets/words` به `public/assets/words` منتقل شد. هر ۱۲۱ تصویر عمومی واژه‌ها با اصل فایل یکسان است. SVGهای یونیت‌های ابتدایی و نمایش عددهای یونیت ۱۳ از دادهٔ موجود استفاده می‌کنند؛ تصویری تولید نشده است.
- `app/first-lesson-types.ts` و `app/layout.tsx`: ارسال واژه‌های بخش سوم به رابط؛ `app/site-shell.tsx`: آدرس بخش سوم؛ `app/first-lesson.tsx`: استفادهٔ دوباره از نمایش واژه، تلفظ و فلش‌کارت بخش اول، بدون مخلوط‌شدن دو مجموعه.
- راهنمای تدریس، تصاویر، ترجمه‌ها، قبلی/بعدی/برگشت، منو و کنترل سرعت/قطع/تکرار صدا مطابق نمونه‌اند. فایل صوتی موجود ساحل در بخش سوم یونیت ۱۵ نیز نمایش داده می‌شود.
- CSS نمونه، داده‌های اصلی و پوشهٔ legacy تغییر نکرده‌اند. اسکن کتابی کپی یا درخواست نشده و `BOOK_SCANS_ENABLED=false` است.

## آزمون‌ها

- `npm run lint` و `npm run build`: موفق.
- `node scripts/verify-data.mjs`: صفر خطای انتقال؛ ۱۶۱ واژه، ۹۹ پرسش گرامر و ۷۹ جملهٔ مدل در کل داده‌ها. کمبود قبلی دو مرجع Student Book یونیت ۱۳ همچنان متعلق به نمونه است و به این بخش مربوط نیست.
- `compare-t4b-3.mjs`: متن و ترتیب هر ۱۵ یونیت با نمونه مقایسه شد؛ تلفظ هر ۷۷ واژه، تمام کارت‌ها و مرزهای آن‌ها، برگشت، جدا بودن مجموعه‌های دو بخش، سرعت/قطع/تکرار، توقف هنگام تغییر بخش، منو، قبلی/بعدی، بازخوانی و تاریخچه بررسی شد. فایل MP3 ساحل بارگذاری می‌شود. خطای مرورگر یا درخواست اسکن ثبت نشد.
- تلفظ خودکار با جایگزین آزمایشی SpeechSynthesis بررسی شد؛ شنیدن صدای واقعی به صدای انگلیسی دستگاه وابسته است.
- آزمون‌های قبلی بخش اول و جمله‌سازی روی همین نسخه دوباره اجرا شدند و موفق بودند؛ خروجی‌ها در `regression-1/` و `regression-2/` نگهداری می‌شوند. آزمون انتخاب بخش ساخته‌نشده اکنون بخش چهارم را انتخاب می‌کند. مسیر خروجی جداست تا گزارش‌های قبلی دست‌نخورده بمانند. جمله‌سازی ۶۰ مقایسهٔ بدون اختلاف داشت. از ۳۲ مقایسهٔ بخش اول، فقط یونیت ۱۳ دسکتاپ در تم روشن ۱۴ پیکسل (حداکثر ۲ واحد) و در تم تاریک ۱۶ پیکسل (حداکثر ۱ واحد) اختلاف داشت؛ این همان تفاوت جزئی پیشینِ بخش اول است.

## تطبیق ظاهر و محدودیت‌ها

۸۰ مقایسهٔ تصویری بخش سوم در عرض‌های ۳۹۰ و ۱۲۸۰ و تم روشن/تاریک انجام شد: صفحهٔ هر ۱۵ یونیت، فلش‌کارت یونیت‌های ۱، ۴، ۱۳، ۱۵ و منوی باز. همهٔ تصاویر ارتفاع یکسان و صفر پیکسل اختلاف داشتند. تصاویر جفتی و `report.json` در همین پوشه‌اند.

فونت نمونه فقط در مرورگر آزمون از فایل‌های محلی تأمین و حرکت‌ها در هر دو صفحه خاموش شدند. محدودهٔ مقایسه از بالای صفحه تا پایان کنترل صداست؛ پابرگ درخواستی قبلی که نمونه ندارد خارج از محدوده است و مخفی نشده است. آزمون‌ها نوسان شناخته‌شدهٔ رندر سربرگ (حداکثر ۱۰۰ پیکسل با اختلاف ۲ از ۲۵۵) را مجاز می‌دانند؛ محتوای بخش جدید باید دقیقاً یکسان باشد. آزمون بخش اول استثنای قبلی یونیت ۱۳ دسکتاپ را حفظ می‌کند: حداکثر ۳۰ پیکسل با اختلاف ۲ واحد.

محتوای واژگان بخش سوم برای هیچ یونیتی ناقص نیست. دکمه‌های تمرین و ویدیو همچنان پیام آماده‌سازی دارند؛ اجرای آن‌ها در T5 و T8 است. پایان کارت‌ها پیشرفت ساختگی ثبت نمی‌کند. بسته‌ای نصب نشده است.

## آزمایش دستی و اجرای دوباره

آدرس: `http://localhost:3017/#tab=lessons&u=1&lesson=3`.

روی واژه کلیک کنید؛ کارت‌ها را باز کنید و تا آخر بروید، سپس برگردید. از منو یونیت ۱۳ و ۱۵ را امتحان کنید. بین سه بخش اول جابه‌جا شوید و تم روشن/تاریک را تغییر دهید.

پس از build، سرور را با `npm run start -- --port 3017` اجرا کنید. سپس در ترمینال دیگر:

```powershell
$env:VISUAL_BASE_URL='http://localhost:3017'
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-3'
node visual-checks/compare-t4b-3.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-3/regression-1'
node visual-checks/compare-t4b-1.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-3/regression-2'
node visual-checks/compare-t4b-2.mjs
```
