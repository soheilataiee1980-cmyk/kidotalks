# نتیجهٔ T4b.4 — حروف و صداها

بخش چهارم مطابق تابع نهایی `lessonTeaching(4)` نمونه پیاده شده است. بخش پنجم شروع نشده است.

## محتوای موجود و هدف

هدف، شناخت حرف یا ترکیب رنگی در کلمه و شنیدن کلمهٔ کامل است. یونیت ۷ مرور نام و ترتیب ۲۶ حرف بزرگ و کوچک است. تمام محتوا از `phonics` در داده‌های موجود آمده؛ راهنمای فارسی و ساختار نمایش عین نمونه است.

| یونیت | تعداد کلمه / حرف |
|---|---:|
| ۱ تا ۴ | هرکدام ۴ کلمه |
| ۵ و ۶ | هرکدام ۵ کلمه |
| ۷ | ۲۶ حرف |
| ۸ تا ۱۵ | هرکدام ۳ کلمه |
| مجموع | ۵۰ کلمه و ۲۶ حرف |

قبل از پیاده‌سازی کمبود دادهٔ لازم برای این بخش یافت نشد. مقدار خالی عنوان فونیکس در یونیت‌های ۱ تا ۳ و ترجمه/ایموجی برخی مدخل‌ها مطابق دادهٔ اصلی است؛ نمای نهایی نمونه از آن‌ها استفاده نمی‌کند. یونیت ۷ عمداً فهرست کلمه ندارد و از رشتهٔ الفبا استفاده می‌کند. تصویر، اسکن، ویدیو یا فایل صوتی مستقل در نمای آموزش این بخش وجود ندارد. تلفظ مرورگر، کلمهٔ کامل یا نام حرف را می‌خواند؛ صدای خالص فونم تولید نشده است.

## تغییرات

- `app/phonics-lesson.tsx`: راهنما، کلمات با `<mark>` در محل اصلی حرف/ترکیب، دکمهٔ تلفظ و الفبای بزرگ/کوچک.
- `app/first-lesson-types.ts` و `app/layout.tsx`: ارسال دادهٔ موجود فونیکس به رابط.
- `app/first-lesson.tsx` و `app/site-shell.tsx`: فعال‌سازی بخش چهارم در تب‌ها، منو، قبلی/بعدی و آدرس `lesson=4` با کنترل صدای موجود.
- `visual-checks/compare-t4b-4.mjs`: آزمون جدید. آزمون‌های قبلی فقط برای انتخاب بخش پنجمِ هنوز ساخته‌نشده به‌جای بخش چهارم به‌روز شدند.
- CSS، داده‌های آموزشی، رسانه‌ها و legacy تغییر نکردند. بسته‌ای نصب نشده و بک‌اندی اضافه نشده است.

## آزمون بخش چهارم

- `npm run lint` و `npm run build`: موفق.
- `node scripts/verify-data.mjs`: صفر خطای انتقال. کمبود قبلی دو مرجع اسکن Student Book یونیت ۱۳ مربوط به این بخش نیست.
- متن راهنما، ترتیب کلمه‌ها و محل حروف برجسته با DOM نمونه در هر ۱۵ یونیت تطبیق داده شد؛ از جمله x در انتهای box، ترکیب‌ها در ابتدا/میانه/انتهای کلمه و واکه‌های کوتاه.
- تمام ۵۰ دکمهٔ کلمه و ۲۶ دکمهٔ حرف در هر چهار ترکیب اندازه/تم آزمایش شدند. کنترل سرعت، قطع/وصل، تکرار، توقف هنگام تغییر بخش، تب‌ها، منو، قبلی/بعدی، تاریخچه و بازخوانی موفق بودند.
- حالت نبود قابلیت گفتار مرورگر پیام درست نشان می‌دهد. آزمون تلفظ از جایگزین آزمایشی SpeechSynthesis استفاده می‌کند؛ کیفیت و صدای واقعی به صدای انگلیسی نصب‌شده روی دستگاه وابسته است.
- هیچ خطای مرورگر یا درخواست اسکن کتاب ثبت نشد. `BOOK_SCANS_ENABLED=false` باقی مانده و `public/assets/book` وجود ندارد.
- تمرین‌ها و ویدیوها طبق تقسیم‌بندی TASKS برای T5 و T8 باقی‌اند؛ دکمه‌ها پیام وضعیت می‌دهند و محتوای ساختگی نشان نمی‌دهند.

## مقایسهٔ تصویری

۶۰ جفت تصویر برای هر ۱۵ یونیت در عرض‌های ۳۹۰ و ۱۲۸۰، تم روشن و تاریک: همه صفر پیکسل اختلاف و ارتفاع یکسان داشتند. فایل‌های `*-prototype.png` و `*-new.png` همراه `report.json` در همین پوشه‌اند.

Chrome و Playwright موجود استفاده شدند. فونت نمونه فقط در مرورگر آزمون از فایل‌های محلی تأمین شد؛ حرکت‌ها برای هر دو صفحه خاموش شدند. تم با `data-theme` ریشه تنظیم شد. محدودهٔ مقایسه از بالای صفحه تا پایان کنترل صداست؛ پابرگ سفارشی قبلی که نمونه ندارد خارج از این محدوده است و مخفی نشده است. معیار آزمون برای محتوای درس تطابق دقیق است؛ فقط نوسان شناخته‌شدهٔ سربرگ تا ۱۰۰ پیکسل/۲ واحد مجاز است که در اجرای این بخش رخ نداد.

## بازآزمایی بخش‌های قبلی

- بخش اول: آزمون واژه‌های ۱۵ یونیت، تصاویر، فلش‌کارت، کنترل صدا، فایل ساحل و منو موفق بود. از ۳۲ مقایسه فقط یونیت ۱۳ دسکتاپ روشن ۳۰ پیکسل با اختلاف حداکثر ۲ از ۲۵۵ داشت؛ این تفاوت جزئی از قبل ثبت شده و در محدودهٔ معیار قبلی آزمون است.
- جمله‌سازی: تلفظ ۶۳ مثال، ناوبری، خانه و فهرست کتاب‌ها موفق بود؛ هر ۶۰ مقایسه صفر اختلاف داشت.
- واژه‌های بیشتر: هر ۷۷ واژه، تمام کارت‌ها، جدا بودن مجموعه‌ها، صدا، منو، تاریخچه و بازخوانی موفق بود؛ هر ۸۰ مقایسه صفر اختلاف داشت.
- خروجی بازآزمایی‌ها در پوشه‌های `regression-1/`، `regression-2/` و `regression-3/` ذخیره می‌شود تا گزارش‌های قبلی تغییر نکنند.

## اجرای دوباره و آزمایش دستی

پس از build، سرور را با `npm run start -- --port 3018` اجرا کنید. آدرس مستقیم: `http://localhost:3018/#tab=lessons&u=1&lesson=4`.

۱. روی «🔊 apple» بزنید؛ باید کلمهٔ کامل شنیده شود. سرعت آهسته، قطع/وصل و تکرار را امتحان کنید.
۲. از منوی یونیت‌ها یونیت ۶ را انتخاب کنید، سپس «حروف و صداها»؛ x در پایان box رنگی است.
۳. یونیت ۷ را انتخاب کنید و دوباره بخش چهارم را باز کنید؛ حروف A a تا Z z را لمس کنید.
۴. با «درس قبلی» به واژه‌های بیشتر و با «درس بعدی» به بخش چهارم برگردید. بازخوانی صفحه باید بخش چهارم را نگه دارد. بخش پنجم هنوز فقط پیام آماده‌سازی دارد.
۵. تم روشن/تاریک و عرض موبایل/دسکتاپ را بررسی کنید.

```powershell
$env:VISUAL_BASE_URL='http://localhost:3018'
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-4'
node visual-checks/compare-t4b-4.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-4/regression-1'
node visual-checks/compare-t4b-1.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-4/regression-2'
node visual-checks/compare-t4b-2.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-4/regression-3'
node visual-checks/compare-t4b-3.mjs
```
