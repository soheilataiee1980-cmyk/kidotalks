# نتیجهٔ T4b.2 — جمله‌سازی

فقط بخش دوم اضافه شده است. زیرکارهای T4b.3 و بعد از آن ناتمام‌اند. بازی‌ها و اتصال ویدیو همچنان مربوط به T5 و T8 هستند و دکمه‌های آن‌ها پیام وضعیت نشان می‌دهند.

## محتوا و رفتار

- راهنمای تدریس هر ۱۵ یونیت از `grammar.teachingTips` آمده است.
- مثال‌ها از `modelSets` انتخاب شده‌اند: برای یونیت ۱، مجموعهٔ `teacherModels()` با ۲ مثال؛ برای یونیت ۲، مجموعهٔ اصلی COURSE با ۹ مثال؛ برای ۱۳ یونیت دیگر، مجموعهٔ اصلی COURSE با ۴ مثال. مجموع ۶۳ مثال است؛ مجموعه‌های آرشیوی با صفحهٔ فعلی مخلوط نشده‌اند.
- متن داده‌های اصلی تغییر نکرده است. نمایش و تلفظ آپاستروف‌ها فقط همان تبدیل `cleanCourse` نمونه را اعمال می‌کند.
- راهنما، ترجمه، دکمهٔ شنیدن و متن «حالا نوبت توست» عین نمونه‌اند. بخش دوم در نمونه تصویر، اسکن یا فایل صوتی مستقل ندارد؛ تلفظ از همان کنترل صدای مرورگر استفاده می‌کند.
- محتوای مورد نیاز بخش دوم برای همهٔ یونیت‌ها موجود است. اگر مجموعه‌ای واقعاً خالی باشد، فقط پیام نبود محتوا نمایش داده می‌شود؛ مثال ساختگی تولید نمی‌شود.
- تب‌ها، منوی بازشونده و دکمه‌های قبلی/بعدی بین بخش‌های ۱ و ۲ کار می‌کنند. `lesson=2` در آدرس، بازخوانی و تاریخچهٔ مرورگر پشتیبانی می‌شود. انتخاب یونیت از منو مثل نمونه به بخش اول آن یونیت می‌رود.
- هنگام تعویض بخش یا خروج، تلفظ جاری لغو و پاسخ صوتی دیررس نادیده گرفته می‌شود. سرعت و قطع صدا در جابه‌جایی بین دو بخش باقی می‌مانند.

## آزمون‌ها

- `npm run lint` و `npm run build`: موفق.
- `node scripts/verify-data.mjs`: صفر خطای انتقال؛ داده‌ها و legacy تغییر نکردند. دو مرجع خالی Student Book یونیت ۱۳ همچنان کمبود خود نمونه‌اند و به این بخش مربوط نیستند.
- `node visual-checks/compare-t4b-2.mjs`: متن و ترتیب راهنماها، ترجمه‌ها و مثال‌های هر ۱۵ یونیت با DOM نمونه تطبیق داده شد. دکمهٔ تلفظ تک‌تک ۶۳ مثال، سرعت، قطع/وصل، تکرار، توقف هنگام تغییر بخش، تب‌ها، منو، قبلی/بعدی، بازگشت مرورگر، بازخوانی، خانه و فهرست ۱۵ یونیت موفق بودند.
- آزمون گفتار از جایگزین آزمایشی SpeechSynthesis استفاده می‌کند؛ ارسال متن درست و رفتار کنترل‌ها تأیید شده است. شنیدن صدای واقعی به صدای انگلیسی نصب‌شده روی دستگاه وابسته است.
- آزمون T4b.1 دوباره روی همین build اجرا شد: واژه‌های هر ۱۵ یونیت، بارگذاری تصاویر، تعداد شش/هفت بخش، فلش‌کارت، منو، کنترل صدا، حالت نبود قابلیت گفتار و فایل MP3 ساحل موفق بودند. خلاصه در `vocabulary-regression-report.json` است. آزمون قدیمی فقط برای انتخاب بخش سومِ هنوز ساخته‌نشده، به‌جای بخش دومِ اکنون فعال، به‌روز شد.
- هیچ خطای مرورگر یا درخواست اسکن کتاب ثبت نشد. `BOOK_SCANS_ENABLED=false` باقی مانده است. فایل رسانه‌ای تازه‌ای اضافه نشده است.

## مقایسهٔ تصویری

۶۰ مقایسه: همهٔ ۱۵ یونیت، عرض‌های ۳۹۰ و ۱۲۸۰ پیکسل، تم روشن و تاریک با تنظیم `data-theme` ریشه. Chrome و Playwright موجود استفاده شدند؛ بسته‌ای نصب نشد. فونت نمونه فقط در مرورگر آزمون از همان فایل‌های محلی بارگذاری و حرکت‌ها در هر دو صفحه خاموش شدند.

در اجرای نهایی، هر ۶۰ مقایسه صفر پیکسل اختلاف و ارتفاع کاملاً یکسان داشت. تصاویر `*-prototype.png` و `*-new.png` و اعداد `report.json` در همین پوشه‌اند. ناحیهٔ مقایسه از بالای صفحه تا پایان کنترل صداست؛ پابرگ درخواستی قبلی، که نمونه ندارد، خارج از این ناحیه است و مخفی نشده است.

در یک اجرای مقدماتی، سربرگ شیشه‌ای موبایل ۸۶ پیکسل با اختلاف حداکثر ۲ از ۲۵۵ داشت؛ در اجرای نهایی این اختلاف دیده نشد. اسکریپت برای این تغییر جزئی رندر فقط در محدودهٔ سربرگ حداکثر ۱۰۰ پیکسل/۲ واحد اجازه می‌دهد؛ محتوای پایین سربرگ باید دقیقاً یکسان باشد. آزمون مجدد T4b.1 نیز فقط اختلاف جزئی قبلی یونیت ۱۳ دسکتاپ تاریک (۳۰ پیکسل، حداکثر ۲ واحد) را نشان داد.

## اجرای دوباره

پس از build، سرور را روی پورت ۳۰۱۶ اجرا کنید:

```powershell
npm run start -- --port 3016
```

در ترمینال دیگر:

```powershell
node visual-checks/compare-t4b-2.mjs
$env:VISUAL_BASE_URL='http://localhost:3016'
node visual-checks/compare-t4b-1.mjs
```

آدرس آزمایش دستی: `http://localhost:3016/#tab=lessons&u=1&lesson=2`.
