# اصلاح قبلی اندازهٔ کارت‌های T5c

این گزارش اکنون فقط برای اصلاح اندازهٔ کارت‌ها معتبر است؛ آزمون کارت و رفتار بازی در همین پوشه نگه داشته شده است.

بخش روباهِ این گزارش و تصویرهای `approved-*` منسوخ‌اند: آن‌ها اشتباهاً لوگوی `BrandMark` را به‌جای آواتار پروفایل در نظر گرفته بودند. نتیجهٔ فعلی باید آواتار پروفایل فعال را نشان دهد. منبع و آزمون معتبر روباه پیش‌فرض، آواتار انتخاب‌شده و صفحه‌های نتیجه در `visual-checks/t5c-avatar/README.md` هستند.

`BOOK_SCANS_ENABLED` همچنان `false` است.
