# بررسی T4b.1 — واژه‌های تازه

فقط بخش اول پیاده شده است. T4b و زیرکارهای ۲ تا ۷ ناتمام‌اند. بخش‌های دیگر، ویدیو و تمرین‌ها پیام وضعیت دارند؛ محتوا یا بازی ساختگی اضافه نشده است. پایان کارت‌ها هم فعلاً همین پیام را نشان می‌دهد و امتیاز آموزشی ثبت نمی‌کند.

## بررسی رفتار

- متن و ترتیب واژه‌های بخش اول هر ۱۵ یونیت مستقیماً با صفحهٔ نمونه مقایسه شد.
- تصاویر هر ۱۵ یونیت بارگذاری شدند. ۶۹ تصویر واژه و فایل صوتی ساحل، بدون تغییر بایت، از فایل‌های موجود استفاده می‌کنند.
- انتخاب یونیت از منو، بازخوانی صفحه، شش بخش برای یونیت‌های ۱ و ۳ و هفت بخش برای بقیه بررسی شد.
- باز و بسته شدن منو و Escape، کارت اول/آخر، قبلی/بعدی، برگشت و پیام بخش‌های ساخته‌نشده بررسی شد.
- فراخوانی تلفظ، زبان انگلیسی، سرعت، قطع صدا و تکرار با جایگزین آزمایشی SpeechSynthesis بررسی شد؛ نبود این قابلیت نیز پیام مناسب می‌دهد. کیفیت صدای واقعی به صدای انگلیسی نصب‌شده روی دستگاه بستگی دارد.
- فایل واقعی MP3 یونیت ۱۵ بارگذاری شد و مرورگر مدت معتبر آن را خواند.
- خطای مرورگر یا درخواست اسکن کتاب مشاهده نشد. BOOK_SCANS_ENABLED همچنان false است و هیچ پوشهٔ اسکن در public وجود ندارد.
- npm run lint و npm run build موفق شدند.

## مقایسهٔ تصویری

۳۲ مقایسه با Chrome و Playwright موجود، در عرض‌های ۳۹۰ و ۱۲۸۰ و تم روشن/تاریک انجام شد: صفحهٔ واژه‌های یونیت‌های ۱، ۲، ۳، ۴، ۱۳ و ۱۵، منوی باز و فلش‌کارت. این موارد SVGهای قدیمی، تصاویر واژه، تفاوت تعداد بخش‌ها و فایل صوتی ساحل را پوشش می‌دهند.

تصاویر از بالای صفحه تا پایان کنترل صدا هستند؛ پابرگ درخواستی قبلی خارج از ناحیهٔ مقایسه است و مخفی نشده است. فونت نمونه فقط در مرورگر آزمون با فایل‌های محلی یکسان بارگذاری شد و حرکت‌ها در هر دو صفحه خاموش شدند. legacy و CSS اصلی تغییر نکردند. تم روشن/تاریک با data-theme ریشه تنظیم شد؛ اولویت رنگ‌بندی بخش‌ها مثل خود نمونه باقی مانده است.

۳۰ مقایسه بدون اختلاف پیکسل بود. در یونیت ۱۳ دسکتاپ، روشن: ۳۰ پیکسل با اختلاف حداکثر ۲ از ۲۵۵؛ تاریک: ۱۶ پیکسل با اختلاف حداکثر ۱ از ۲۵۵ باقی ماند. تمام ارتفاع‌ها یکسان‌اند. آستانهٔ آزمون فقط برای همین مورد محدود شده است؛ بقیه باید دقیقاً یکسان باشند. اعداد هر اجرا در report.json ثبت می‌شوند.

## اجرای دوباره

سرور تولیدی را روی پورت ۳۰۱۵ اجرا کنید و سپس از ریشهٔ پروژه:

```powershell
node visual-checks/compare-t4b-1.mjs
```

برای آدرس دیگر، VISUAL_BASE_URL را تنظیم کنید. اسکریپت از Playwright و Sharp موجود در محیط Codex این رایانه و Chrome نصب‌شده استفاده می‌کند و بسته‌ای نصب نمی‌کند.
