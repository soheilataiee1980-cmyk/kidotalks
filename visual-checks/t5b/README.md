# گزارش دیداری و آزمون T5b

بازی تطبیق، تصویر هر واژه را به واژهٔ انگلیسی آن وصل می‌کند؛ معنی فارسی در نام دسترس‌پذیر هر دو دکمه آمده است. گروه‌ها حداکثر چهار واژه دارند و با محتوای واقعی همان یونیت ساخته می‌شوند.

هر ۱۵ یونیت بررسی شد. بانک‌ها در مجموع ۱۶۱ واژه دارند و برای همهٔ آن‌ها تصویر موجود است: یونیت‌های ۱ تا ۳ از SVGهای موجود استفاده می‌کنند؛ بقیه SVG، ایموجی یا تصویر عمومی موجود در `public/assets/words/` دارند. برای T5b محتوای آموزشی یا تصویر گمشده‌ای پیدا نشد. اسکن کتاب در این بخش استفاده نمی‌شود.

نتیجهٔ تطبیق تصویر بازی فعال با نمونهٔ اصلی در Playwright:

| اندازه | تم | پیکسل‌های متفاوت |
|---|---|---:|
| ۳۹۰ | روشن | ۰ از ۲۸۸٬۴۰۸ |
| ۳۹۰ | تیره | ۸ از ۲۸۸٬۴۰۸ |
| ۱۲۸۰ | روشن | ۰ از ۳۷۲٬۴۸۰ |
| ۱۲۸۰ | تیره | ۰ از ۳۷۲٬۴۸۰ |

اختلاف ۸ پیکسلیِ حالت تیرهٔ موبایل به لبهٔ چند دکمه محدود است؛ بیشترین اختلاف رنگ ۴ از ۲۵۵ است و جابه‌جایی یا هم‌پوشانی دیداری ندارد.

آزمون‌های مرورگر جواب اشتباه و بازخوردش، انتخاب تصویر و واژهٔ درست، قفل‌شدن جفت، امتیاز و ستاره، شروع دوباره، کنترل صدا و سرعت، انتخاب هر ۱۵ یونیت و نداشتن بیرون‌زدگی افقی یا روی‌هم‌افتادن دکمه‌ها را بررسی کردند. بخش‌های T4b.1 تا T4b.7 باز شدند و T5a در متن یونیت ۱۵ با جواب اشتباه بررسی شد. هیچ خطای مرورگر یا درخواست اسکن کتاب ثبت نشد. `npm run lint` و `npm run build` موفق بودند.

تصاویر مقایسه در همین پوشه ذخیره شده‌اند؛ فایل `report.json` خروجی عددی را نگه می‌دارد و `../compare-t5b.mjs` آزمون را دوباره اجرا می‌کند.
