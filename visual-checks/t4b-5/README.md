# نتیجهٔ T4b.5 — خواندن و فهمیدن

فقط بخش پنجم پیاده شد؛ بخش ششم و کارهای بعدی شروع نشده‌اند.

## محتوا

- برای هر ۱۵ یونیت، متن اصلی درس و پرسش‌های فهم آن در `data/units` موجود است. متن و پرسش‌ها بدون تغییر از همان دادهٔ تایپ‌شده به رابط درس می‌رسند؛ پرسش‌ها فعلاً نمایش داده نمی‌شوند چون نمونه در حالت «یاد بگیر» فقط متن و دکمهٔ شنیدن را نشان می‌دهد. داده‌ها برای اتصال تمرین در کار بعدی آماده‌اند.
- راهنمای سه‌مرحله‌ای و دکمهٔ خواندن صوتی مطابق `lessonTeaching(5)` نمونه است. متن با همان تبدیل آپاستروف نمونه نمایش داده و خوانده می‌شود.
- یادداشت کاردستی یونیت ۳ از خود نمونه حفظ شد.
- برای یونیت‌های ۱ تا ۳ متن جداگانهٔ Workbook وجود ندارد (`workbookReading: null`). متن اصلی خواندن این یونیت‌ها در داده موجود است و استفاده می‌شود؛ متن جایگزین یا اسکن کتاب اضافه نشده است. برای محتوای همین بخش کمبود دیگری پیدا نشد. اسکن، تصویر، صدای ضبط‌شده یا ویدیوی مرتبط در نمای نمونهٔ این درس وجود ندارد.

## فایل‌ها

- `app/reading-lesson.tsx`: راهنمای خواندن، متن انگلیسی، یادداشت یونیت ۳ و دکمهٔ صدا.
- `app/first-lesson-types.ts` و `app/layout.tsx`: عبور دادهٔ خواندن و پرسش‌های اصلی.
- `app/first-lesson.tsx` و `app/site-shell.tsx`: اتصال بخش پنجم به تب‌ها، منو، نشانی درس و کنترل صدا.
- `visual-checks/compare-t4b-5.mjs`: بررسی متن، پرسش‌ها، رفتار و تصاویر.
- `visual-checks/compare-t4b-1.mjs` تا `compare-t4b-4.mjs`: آزمون‌های بازگشت به‌روزرسانی شدند تا بخش ششم را به‌عنوان بخش پیاده‌نشده بسنجند.
- `TASKS.md`: وضعیت T4b.5 به‌روز شد. داده‌های اصلی و `legacy/` تغییر نکردند؛ بسته‌ای نصب نشد.

## آزمون‌ها

- `npm run lint` و `npm run build`: موفق.
- `node scripts/verify-data.mjs`: صفر خطای انتقال؛ داده‌های آموزشی موجودند. دو مرجع خالی Student Book یونیت ۱۳، کمبود ثبت‌شدهٔ خود نمونه است و به این درس مربوط نیست.
- آزمون Playwright تطبیق متن و راهنما، دکمهٔ شنیدن هر ۱۵ متن، اصلاح آپاستروف، کنترل سرعت، قطع و تکرار صدا، توقف صدا هنگام جابه‌جایی، منو، تب‌ها، قبلی/بعدی، بازخوانی، پیوند به دادهٔ پرسش‌ها، یادداشت یونیت ۳، نبود متن Workbook در یونیت‌های ۱ تا ۳، پیام بخش ششم، خطاهای مرورگر و درخواست اسکن را بررسی کرد؛ موفق.
- آزمون بازگشت T4b.1 تا T4b.4 همگی موفق شدند. جمله‌سازی، واژه‌های بیشتر و حروف و صداها دقیقاً مطابق نمونه ماندند. در بخش اول، آزمون قبلیِ یونیت ۱۳ دسکتاپ تاریک یک اختلاف محدود ۳۰ پیکسلی با حداکثر شدت ۲ از ۲۵۵ نشان داد؛ آزمون همان حد از پیش تعیین‌شده را اعمال می‌کند. بازآزمایی این نوبت اختلاف دیگری نشان نداد.
- تلفظ با جایگزین آزمایشی SpeechSynthesis آزمایش شد؛ صدای شنیدنی واقعی به صدای انگلیسی دستگاه بستگی دارد. هیچ خطای مرورگر یا درخواست اسکن ثبت نشد. `BOOK_SCANS_ENABLED=false` است و پوشهٔ `public/assets/book` وجود ندارد.

## تطبیق تصویری

۶۰ مقایسه برای هر ۱۵ یونیت در عرض‌های ۳۹۰ و ۱۲۸۰، تم روشن و تاریک انجام شد؛ هر ۶۰ مورد صفر پیکسل اختلاف و ارتفاع یکسان داشت. تصاویر جفتی و `report.json` در همین پوشه ذخیره شده‌اند. محدوده از بالای صفحه تا پایان کنترل صداست و پابرگ سفارشی خارج آن قرار دارد.

## آزمایش دستی

پس از build، سرور را با `npm run start -- --port 3019` اجرا کنید و این نشانی را باز کنید: `http://localhost:3019/#tab=lessons&u=1&lesson=5`.

دکمهٔ «🔊 شنیدن متن» را بزنید و سرعت، قطع صدا و تکرار را آزمایش کنید. از منو یونیت ۳ را انتخاب کنید تا متن و دستور کاردستی را ببینید. سپس با «درس قبلی/بعدی» بین فونیکس و خواندن بروید، صفحه را بازخوانی کنید و تم روشن/تاریک و اندازهٔ موبایل/دسکتاپ را امتحان کنید. انتخاب درس ششم باید پیام آماده‌سازی را نشان دهد.

برای اجرای آزمون‌ها پس از build:

```powershell
$env:VISUAL_BASE_URL='http://localhost:3019'
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-5'
node visual-checks/compare-t4b-5.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-5/regression-1'
node visual-checks/compare-t4b-1.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-5/regression-2'
node visual-checks/compare-t4b-2.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-5/regression-3'
node visual-checks/compare-t4b-3.mjs
$env:VISUAL_OUTPUT_DIR='visual-checks/t4b-5/regression-4'
node visual-checks/compare-t4b-4.mjs
```
